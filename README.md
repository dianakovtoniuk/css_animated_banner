# Animated Banner

A hero banner with a floating 3D-style heading and a randomly generated twinkling starfield. Built with HTML, CSS and vanilla JavaScript.

## Features

- 200 stars generated by JavaScript at random positions, sizes and blink speeds
- Heading with layered text shadows for a 3D look, skewed and floating up and down
- Orange ring behind the text for depth
- Fully responsive sizing using viewport units

## How it works

`main.js` creates 200 `<i>` elements, gives each one a random position, size and animation duration, and appends them to the section. The glow and the fade in and out are handled in CSS.

## Structure

```
website-animated-banner/
├── index.html
├── style.css
└── main.js
```

## Usage

Clone the repo and open `index.html` in a browser. No build step or dependencies are needed.

## Customization

- Change the star count in the `while (j < 200)` loop in `main.js`
- Edit the heading text in `index.html`
- Change the background and ring colors (`#0d172e`, `#ff9100`) in `style.css`
- Adjust the floating speed in the `floating` animation (`5s`)
